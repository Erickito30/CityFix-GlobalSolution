# CityFix — Global Solution

Plataforma onde moradores registram problemas urbanos do bairro, apoiam os mais urgentes e acompanham o andamento até a solução.

## Problema
Buracos, calçadas quebradas, iluminação ruim e lixo acumulado afetam o cotidiano e a acessibilidade. O projeto propõe uma forma simples de registrar ocorrências, consultar relatos existentes e acompanhar seu status.

## Como funciona
1. **Registrar:** informar tipo do problema, bairro e descrição.
2. **Ver:** consultar ocorrências e filtrar por tipo, bairro e status.
3. **Apoiar:** apoiar os relatos que também afetam o morador.
4. **Acompanhar:** visualizar os status Aberta, Em análise e Resolvida.

## Estrutura
- `index.html` — página inicial e apresentação do problema e da proposta.
- `solucao.html` — página da solução e espaço reservado para formulário e ocorrências.
- `impacto.html` — página de indicadores e ODS.
- `equipe.html` — integrantes do projeto.
- `css/style.css` — estilos compartilhados, sem CSS inline.
- `js/script.js` — JavaScript compartilhado.
- `img/` — imagens do projeto.

As quatro páginas usam HTML semântico (`header`, `nav`, `main` e `footer`) e compartilham o mesmo menu.
